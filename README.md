# Match de Curriculos API

API Node.js para o projeto de match de curriculos.

## Stack
- Node.js + Express
- MongoDB + Mongoose
- Jest + Supertest + mongodb-memory-server

## Executar localmente
1. Copie `.env.example` para `.env`.
2. Ajuste `DB_URL` para o seu MongoDB local.
3. Instale dependencias:

```bash
npm install
```

4. Suba a API:

```bash
npm run dev
```

## Testes

```bash
npm test
```
